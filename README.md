## 🚀 Selected Projects

### 🤖 EnvAgent

**Automated Conda Environment Building Agent for AI/ML Projects**

* Built an LLM-based agent that analyzes project files, source-code imports, dependencies, and installation logs.
* Automatically generates and repairs Conda `environment.yml` files.
* Implemented AST-based import analysis and execution-feedback-based repair loops.
* Handles missing packages, version conflicts, installation order issues, and build failures.

<br/>

### 📚 [ScholarPilot](https://github.com/hyeokkiyaa/ScholarPilot-V1.0)

**AI Agent for Research Paper Management**

* Organizes academic papers and research materials.
* Supports AI-assisted paper summarization and research workflow management.

<br/>

### 🛡️ Context Guard

**AI Agent Security Dashboard**

* Developed a dashboard that evaluates file and clipboard activity.
* Classifies potentially sensitive actions into `ALLOW`, `WARN`, and `BLOCK`.
* Received an Encouragement Award at the Google AI Agent Program and Competition.

<br/>

### 🦠 Static-Analysis-Based Malware Detection

* Surveyed feature-extraction techniques for ELF, PE, PDF, Word, and Excel files.
* Reproduced static malware detection workflows using EMBER 2024 and LightGBM.
* Analyzed byte histograms, entropy, strings, metadata, and file-specific features.

<br/>

### 🌊 LoRa-Based Maritime Drowning Detection System

* Developed a drowning detection system using TTGO LoRa32, ultrasonic sensors, MPU-6050, Raspberry Pi, and FastAPI.
* Designed a broker-less lightweight publish/subscribe protocol over LoRa.
* Implemented multi-hop relay, ACK-based delivery, duplicate suppression, TTL, and CRC-8 validation.
* Built a real-time monitoring dashboard using FastAPI and WebSocket.

<br/>

### 📡 High-Availability CCTV Event System

* Designed an MQTT-based event delivery system with Active/Backup Core failover.
* Applied LWT failure detection, QoS 1 delivery, and local FIFO store-and-forward.
* Implemented RTT-based relay selection and UUID-based duplicate filtering.
